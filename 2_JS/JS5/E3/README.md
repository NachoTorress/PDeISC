# alumnos-consumidor

Requiere que `alumnos-api` esté corriendo en `http://localhost:3001`.

1. Instalar dependencias: `npm install`
2. Iniciar: `npm start` (o `PORT=3002 npm start`)
3. Abrir `http://localhost:3002`

Si `alumnos-api` corre en otro host/puerto, actualizar `API_URL` en `scripts/api.js`.
