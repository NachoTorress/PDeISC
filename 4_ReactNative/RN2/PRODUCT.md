# Pulso

## Platform

adaptive

## Stack

React Native con Expo SDK 57 y TypeScript, por solicitud del usuario. Android APK mediante EAS. Navegador como vista complementaria mediante React Native Web y Metro.

## Propósito

Ejercicio académico para utilizar cámara, lector de códigos, ubicación GPS, acelerómetro, giroscopio y biometría. El éxito consiste en ejecutar pruebas reales del hardware y conservar resultados locales consultables, editables y eliminables.

## Restricciones confirmadas

Código modular y documentado, controles funcionales, validación inmediata, temas claro y oscuro, diseño adaptable, confirmaciones dentro de cada tarjeta y fecha de creación DD/MM/AA. Sin alert ni confirm del navegador. No se solicitan datos personales ajenos al ejercicio.

## Decisiones de implementación

Nombre Pulso y funcionamiento local elegidos para esta implementación. No hay identidad previa ni activos suministrados. Sin cuentas, servidor o base relacional porque la consigna no los necesita. La biometría es una demostración del sistema y no protege el historial.
