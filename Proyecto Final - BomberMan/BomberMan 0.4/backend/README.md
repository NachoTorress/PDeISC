# Backend (próximo hito)

Esta carpeta queda reservada para la API REST Node.js/Express/TypeScript y los scripts SQL de TiDB Cloud. No hay un servidor funcional todavía: el hito 1 es una partida local. El frontend no contiene credenciales de base de datos.

`.env` es local y está ignorado por Git. `.env.example` registra los nombres de variables sin secretos. En Vercel, las variables del backend se configurarán en el proyecto de la API.
