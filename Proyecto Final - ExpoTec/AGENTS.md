# Instrucciones del proyecto

- Por indicación explícita del usuario, trabajar, hacer commits y pushear directamente en `main`. No crear ramas ni pull requests salvo que el usuario cambie esta instrucción.
- El repositorio Git está en la carpeta superior `PDelSC`; incluir únicamente los cambios de ExpoTec y conservar los cambios locales de los otros proyectos.
- No versionar archivos privados `.env`, contraseñas, tokens ni secretos. Frontend y backend se despliegan por separado en Vercel desde `main`; la base está en TiDB.
