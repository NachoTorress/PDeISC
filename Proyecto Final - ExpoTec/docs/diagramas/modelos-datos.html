Alcance y lectura de las relaciones

El DFD incluye la web, la APK y la API dentro de la frontera de ExpoTec. D1–D6 agrupan tablas en TiDB y D7 representa los archivos de imágenes. El DER muestra restricciones del SQL: una línea no implica por sí sola una regla de autorización o de estado del programa. El modelo general permite ubicar las entidades; las vistas por dominio y el modelo físico completo incluyen todos los atributos.
